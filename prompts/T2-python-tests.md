## Промпт

Ты — инженер по тестированию на Python. Пакет `vitals` в `python/` репозитория
`D:\6 семестр\Методы программирования\lab14`, контракт — `docs/ARCHITECTURE.md`. Напиши
тесты pytest в `tests/unit/` (`asyncio_mode = "auto"` настроен). Существующий
`tests/unit/test_validation_equivalence.py` не меняй. **Ожидания — из контракта.**

### Что покрыть (по модулю — отдельный файл)

1. `vitals.analytics` — каждый шаг очистки на маленьком DataFrame с известными дефектами
   (дубликаты `(device_id, seq)`, единицы, будущий `ts`, вне диапазона, пропуски, `battery`)
   и отчёт по шагам (числа); агрегаты (SUM/AVG/MIN/MAX/COUNT) против ручного расчёта;
   эпизоды по правилам раздела 7; DuckDB и Polars дают одинаковый результат на одном
   Parquet (`tmp_path`).
2. `vitals.streaming` — скользящее окно (5 мин, шаг 10 с) на фейковых часах: выход старых
   корзин, опоздавшие и будущие события, ограничение памяти (`prune`); правила тревог на
   граничных значениях (120, 92, 38.0, 160, 20%); гистерезис: тревога не дублируется и
   снимается только после 30 с без условия; идемпотентность по `(device_id, seq)`.
3. `vitals.dashboard` — `create_app` с фейковой шиной через `httpx.ASGITransport` и
   `TestClient` для WebSocket: `/healthz`, `/api/snapshot`, `/api/alerts` с пагинацией,
   заголовки (CSP без `unsafe-inline`, `Referrer-Policy: same-origin`), WS с чужим `Origin`
   отклоняется, медленный клиент не блокирует рассылку другим (`Hub`), в `static/*.js` нет
   `innerHTML`.
4. `vitals.pycollector` — tumbling-окна (те же ожидания, что раздел 2.4), формат JSONL raw
   и agg по контракту, пакетная запись по размеру.
5. `vitals.bench.stats` — медиана, сводка прогонов, коэффициент сокращения.

### Ограничения

- Код приложения **не меняй**. Ошибку — оставь падающим тестом с комментарием `# НАХОДКА:`
  и перечисли в ответе. Не импортируй приватные функции (с `_`) из модулей.
- `.venv\Scripts\python`. В конце один раз: `ruff check tests` и
  `python -m pytest tests -q --cov=vitals`. Не гоняй цикл «запустил → поправил» больше двух
  раз на файл; тест, который не получается за две попытки, — пропусти и упомяни.
- Не трогай `go/`, `rust/`. Не делай git-коммитов. Файлы — инструментом Write.
